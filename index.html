Ferramenta · Otimização de tokensRepositório ↗

RTK — Rust Token Killer

Ferramenta CLI para compactar saídas de comandos e reduzir tokens enviados aos agentes. Não é uma skill. Instale o executável uma única vez; depois configure cada agente separadamente.

🍎 Instalação no Mac · uma vez só

1. Instalar RTK no macOS (Homebrew)
brew install rtk-ai/tap/rtk
2. Conferir instalação
rtk --version

Se você já instalou o RTK, pule esta etapa. Os comandos abaixo configuram os agentes, não reinstalam o programa.

🟠 CLAUDE CODE · configuração global

1. Prévia das alterações (sem modificar arquivos)
rtk init -g --dry-run
2. Configurar hook global do Claude Code
rtk init -g

Quando aparecer a pergunta sobre alterar ~/.claude/settings.json, revise e confirme com y. O RTK registra o hook rtk hook claude, cria/atualiza ~/.claude/RTK.md e preserva um backup do settings.json ao modificá-lo.

3. Verificar registro do hook
rtk init --show

🟢 CODEX · configuração global

1. Prévia das alterações (sem modificar arquivos)
rtk init -g --codex --dry-run
2. Configurar hook global do Codex
rtk init -g --codex

O RTK cria/atualiza ~/.codex/RTK.md, ~/.codex/AGENTS.md e ~/.codex/hooks.json. Reinicie o Codex e revise eventuais solicitações de confiança no hook.

3. Conferir arquivo do hook
cat ~/.codex/hooks.json

✅ Depois de configurar os dois

Feche e abra novas sessões do Claude Code e do Codex. Execute comandos compatíveis nos agentes e consulte as estatísticas. O teste manual abaixo verifica a ferramenta, mas não comprova que os hooks automáticos foram acionados.

Testar compactação diretamente
rtk ls
Ver estatísticas de economia
rtk gain

Se aparecer No tracking data yet, ainda não há comandos registrados. A economia indicada em rtk gain se refere às saídas processadas, não necessariamente ao custo total das sessões.

Prompt sugerido · Claude Code ou Codex

Verifique se o RTK está instalado e se a integração deste agente está ativa. Execute comandos de leitura compatíveis sem alterar arquivos, confirme quais passaram pelo RTK e explique como consultar rtk gain. Não altere configurações automaticamente.

Instalação e configuração globais: afetam os projetos atendidos por cada agente. Revise os hooks antes de autorizá-los. Documentação: guia oficial de configuração ↗.
