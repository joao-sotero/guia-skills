Skills e plugins para Claude Code e Codex

Somente skills e integrações que fornecem instruções para agentes. Inclui skills que dependem de ferramentas externas, como Playwright CLI. Comandos e exemplos para Claude Code e Codex.

Atenção: comandos /plugin e slash commands de plugins são específicos do Claude Code. Para o Codex, as skills compatíveis usam -a codex; CLIs e documentos podem funcionar nos dois, mas hooks e plugins podem exigir adaptação.

Skills para Codex e Claude Code

Excluídos os cards de referências, documentos, plugins sem SKILL.md confirmado, CLIs sem skill identificada e itens pendentes. Playwright CLI foi mantido porque oferece instalação de skill. A instalação do executável CLI pode ser separada da instalação da skill.

SkillDesign de interface

1. Taste Skill

Ajuda o agente a criar interfaces com direção visual mais consistente e menos aparência genérica: composição, tipografia, imagens, microinterações e acabamento.

Repositório: Leonxlnx/taste-skill

No Claude Code — Instalar no projeto no Claude Code
npx skills add https://github.com/Leonxlnx/taste-skill --skill design-taste-frontend -a claude-code
No Claude Code — como usar
“Use a Taste Skill para redesenhar a tela de dashboard deste projeto, mantendo as regras de negócio e melhorando hierarquia visual, tipografia e espaçamento.”
No Codex — instalar ou preparar
npx skills add Leonxlnx/taste-skill -a codex
No Codex — como usar
Peça: “Use Taste Skill para melhorar a hierarquia visual do dashboard Angular, sem mudar a lógica.”

Instale a skill no Codex e abra uma nova sessão. Confira no instalador o nome exato da skill; o repositório pode oferecer mais de uma.

Skill + ferramentaBrowser testing

3. Playwright CLI

Permite ao agente abrir um navegador real, navegar, clicar, preencher formulários, inspecionar páginas e capturar screenshots. A skill ensina o agente a operar o CLI. Requer Node.js 20 ou superior.

Repositório: microsoft/playwright-cli

No Claude Code — Instalar CLI
npm install -g @playwright/cli@latest
No Claude Code — Instalar no projeto
playwright-cli install --skills
No Claude Code — como usar
“Use Playwright CLI para testar o fluxo de login, recuperação de senha e cadastro. Valide cenários de sucesso e erro e salve screenshots.”
No Codex — instalar ou preparar
npm install -g @playwright/cli@latest
playwright-cli install --skills
No Codex — como usar
Peça: “Use Playwright CLI para abrir a aplicação local, testar login e gerar screenshots dos erros.”

O CLI funciona fora dos agentes. Verifique onde o instalador colocou a skill; se for exclusiva do Claude, consulte o README para integrá-la ao Codex ou instrua o Codex a usar o CLI diretamente.

SkillMotion design

4. Emil Kowalski — Skills

Coleção de skills para designers e engenheiros: animações, revisão e melhoria de motion, performance, princípios Apple, prototipação e experiência mobile.

animate, review-animations, improve-animations, find-animation-opportunities, animation-performance, apple-design, prototype, mobile-native, break-ui e pick-ui-library.

No Claude Code — como usar

No Codex — instalar ou preparar
npx skills add emilkowalski/skills -a codex
No Codex — como usar
Peça: “Use a skill de revisão de animações do Emil Kowalski para melhorar easing, duração e reduced motion.”

Se o instalador oferecer seleção, escolha só as skills necessárias; verifique a lista de nomes instalada.

Skill + ferramentaDesign quality

5. Impeccable

Kit de vocabulário e revisão visual para agentes de código. Ajuda a criticar, auditar e refinar interfaces, reduzindo problemas comuns de UI genérica. O instalador pode configurar skill e hook de revisão automática.

Repositório: pbakaus/impeccable

No Claude Code — Instalar
npx impeccable install

O instalador pergunta se a instalação será por projeto ou global e oferece o hook quando suportado. Aceite o hook e reinicie/recarregue o Claude Code. Para atualizar: npx impeccable update.

No Claude Code — como usar
/impeccable init
/impeccable critique
/impeccable audit
/impeccable polish
/impeccable animate

Também pode ser instalado como plugin nativo do Claude Code: adicionar o marketplace pbakaus/impeccable e depois instalar Impeccable pela tela /plugin.

No Codex — instalar ou preparar
npx impeccable install
No Codex — como usar
Peça: “Use os princípios do Impeccable para criticar e refinar o dashboard; preserve a arquitetura Angular.”

No instalador, selecione Codex se essa opção estiver disponível. Não presuma que /impeccable init e outros slash commands do Claude estarão presentes no Codex; use instruções em linguagem natural ou as skills que o instalador criar.

SkillGoogle Stitch

6. DESIGN.md — Stitch design-md

Skill do Google Stitch que analisa telas e metadados de um projeto Stitch e gera um DESIGN.md semântico com tokens, cores, tipografia, espaçamentos e padrões de componentes. Exige acesso ao Stitch MCP Server e um projeto Stitch com pelo menos uma tela.

Repositório: google-labs-code/stitch-skills

No Claude Code — Instalar no projeto
npx skills add google-labs-code/stitch-skills --skill design-md -a claude-code
No Claude Code — como usar
“Analise as telas do meu projeto no Stitch e gere um DESIGN.md completo documentando o sistema visual.”

Sem o Stitch MCP configurado e acesso ao projeto, essa skill não consegue buscar as telas do Stitch.

No Codex — instalar ou preparar
npx skills add google-labs-code/stitch-skills --skill design-md -a codex
No Codex — como usar
Peça: “Com o Stitch MCP configurado, analise as telas do projeto e gere DESIGN.md.”

Sem Stitch MCP e permissão ao projeto, a skill não consegue acessar as telas. A instalação da skill não configura automaticamente o MCP.

SkillAnálise de softwareNova

9. Teardown

Investiga software, apps, sites e documentos existentes para documentar fluxos, comparar abordagens e planejar melhorias baseadas em evidências.

Repositório: PatrickHuntington/teardown

Instalar apenas neste projeto — Codex + Claude
mkdir -p .agents/skills .claude/skills
if [ ! -e .agents/skills/teardown ]; then
  git clone https://github.com/PatrickHuntington/teardown.git .agents/skills/teardown
else
  echo "Teardown já existe em .agents/skills; não sobrescrito"
fi
if [ ! -e .claude/skills/teardown ]; then
  cp -a .agents/skills/teardown .claude/skills/teardown
else
  echo "Teardown já existe em .claude/skills; não sobrescrito"
fi
Prompt de uso
Use a skill teardown para estudar o fluxo de atendimento de um software de clínica que eu indicar. Separe funcionalidades observadas, hipóteses e oportunidades para o Reabilitar. Não copie código proprietário nem altere meu projeto sem autorização.

O repositório oficial documenta instalação por cópia integral da pasta. Os comandos acima preservam a estrutura e evitam sobrescrever uma instalação existente.

Instalação local — skills adicionadas recentemente

Execute a partir da raiz correta do Reabilitar. Não há -g nos comandos. Revise scripts e alterações antes de executar; Floorplan pode inspecionar arquivos sensíveis.

Todos os comandos em um bloco
# Entre na raiz REAL do seu projeto antes de instalar
# Exemplo: cd /caminho/para/REABILITAR

# Unslop (local: Codex e Claude)
npx skills add https://github.com/heydamir/unslop --skill unslop -a codex -a claude-code -y

# Floorplan (local: Codex e Claude)
npx skills add https://github.com/haydenschmitty/floorplan --skill floorplan -a codex -a claude-code -y

# Teardown (local: Codex e Claude; sem sobrescrever)
mkdir -p .agents/skills .claude/skills
if [ ! -e .agents/skills/teardown ]; then git clone https://github.com/PatrickHuntington/teardown.git .agents/skills/teardown; fi
if [ ! -e .claude/skills/teardown ]; then cp -a .agents/skills/teardown .claude/skills/teardown; fi

# Verificar
npx skills list
find .agents/skills .claude/skills -maxdepth 2 -name SKILL.md -print | sort

Prompt mestre para Codex ou Claude Code

Cole em um novo chat com o projeto aberto. Ele solicita análise e plano antes de qualquer mudança.

Você está trabalhando no projeto Reabilitar, um sistema de gestão de clínica com pacientes, atendimentos, Pilates, agenda e financeiro.

Antes de alterar arquivos:
1. Inspecione a estrutura do projeto e localize as skills instaladas em .agents/skills/ e .claude/skills/.
2. Leia os arquivos SKILL.md das skills relevantes. Não invente instruções.
3. Use Floorplan para explicar a arquitetura atual, suas dependências e fluxos principais; não publique mapas ou segredos.
4. Use Teardown somente quando houver sistema, documento ou fluxo de referência a analisar. Diferencie evidências de inferências.
5. Use Unslop para avaliar a qualidade visual das telas existentes e propor ajustes que preservem identidade e funcionalidades. Apresente a direção visual antes de implementar.
6. Selecione outras skills já instaladas apenas quando forem relevantes (por exemplo, web-design-guidelines e impeccable).
7. Proponha um plano priorizado, incluindo testes, riscos e critérios de aceite. Não altere nada até eu aprovar.

Ao responder, informe os caminhos dos SKILL.md realmente lidos e o motivo de cada skill selecionada.

Notas de instalação
  • Execute os comandos de instalação de skills na raiz do projeto Reabilitar. Evite a opção -g para manter as skills locais.
  • Após instalar, abra uma nova sessão do Claude Code se a skill não aparecer.
  • Plugins do Claude Code são instalados com comandos /plugin dentro do próprio Claude Code; não cole esses comandos diretamente no shell.
  • Confira o README e as permissões de qualquer repositório de terceiros antes de instalar. Skills podem incluir scripts e hooks.
