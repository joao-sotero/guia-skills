Skills e plugins para Claude Code e Codex

Todas as ferramentas que você mencionou, com explicação, instalação e exemplo de uso separados para Claude Code e Codex. Clique em Copiar para levar os comandos ao terminal.

Atenção: comandos /plugin e slash commands de plugins são específicos do Claude Code. Para o Codex, as skills compatíveis usam -a codex; CLIs e documentos podem funcionar nos dois, mas hooks e plugins podem exigir adaptação.

Ferramentas confirmadas

SkillDesign de interface

1. Taste Skill

Ajuda o agente a criar interfaces com direção visual mais consistente e menos aparência genérica: composição, tipografia, imagens, microinterações e acabamento.

Repositório: Leonxlnx/taste-skill

No Claude Code — Instalar globalmente no Claude Code
npx skills add https://github.com/Leonxlnx/taste-skill --skill design-taste-frontend -g -a claude-code
No Claude Code — como usar
“Use a Taste Skill para redesenhar a tela de dashboard deste projeto, mantendo as regras de negócio e melhorando hierarquia visual, tipografia e espaçamento.”
No Codex — instalar ou preparar
npx skills add Leonxlnx/taste-skill -g -a codex
No Codex — como usar
Peça: “Use Taste Skill para melhorar a hierarquia visual do dashboard Angular, sem mudar a lógica.”

Instale a skill no Codex e abra uma nova sessão. Confira no instalador o nome exato da skill; o repositório pode oferecer mais de uma.

No Claude Code — Instalar globalmente

No Claude Code — como usar
“Faça uma auditoria desta tela usando Web Design Guidelines. Liste problemas de acessibilidade, UX e responsividade e corrija os que forem seguros.”
No Codex — instalar ou preparar
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -g -a codex
No Codex — como usar
Peça: “Use web-design-guidelines para auditar acessibilidade e responsividade deste formulário e corrija os problemas.”

Use o nome da skill explicitamente ou selecione-a pelo menu de skills do Codex.

ReferênciaDesign system

3. Awesome DESIGN.md

Coleção de exemplos de arquivos DESIGN.md. Cada arquivo descreve linguagem visual — cores, tipografia, componentes, espaçamento, sombras e regras — para orientar a IA a manter consistência. Não é um plugin executável.

Repositório: VoltAgent/awesome-design-md

Instalação / uso
git clone https://github.com/VoltAgent/awesome-design-md.git
No Claude Code — como usar
Escolha um DESIGN.md adequado, copie para a raiz do projeto e peça: “Leia DESIGN.md e trate-o como fonte da verdade visual. Antes de alterar a UI, respeite cores, fontes, espaçamentos e padrões de componentes.”
No Codex — instalar ou preparar
git clone https://github.com/VoltAgent/awesome-design-md.git
No Codex — como usar
Copie um DESIGN.md de referência para a raiz do projeto. Peça: “Leia DESIGN.md e mantenha a identidade visual em todas as alterações.”

Não é uma skill instalável: é uma coleção de exemplos. Vale igualmente para Claude e Codex.

CLI + SkillBrowser testing

4. Playwright CLI

Permite ao agente abrir um navegador real, navegar, clicar, preencher formulários, inspecionar páginas e capturar screenshots. A skill ensina o agente a operar o CLI. Requer Node.js 20 ou superior.

Repositório: microsoft/playwright-cli

No Claude Code — Instalar CLI
npm install -g @playwright/cli@latest
No Claude Code — Instalar skill global para Claude Code
playwright-cli install --skills -g
No Claude Code — como usar
“Use Playwright CLI para testar o fluxo de login, recuperação de senha e cadastro. Valide cenários de sucesso e erro e salve screenshots.”
No Codex — instalar ou preparar
npm install -g @playwright/cli@latest
playwright-cli install --skills -g
No Codex — como usar
Peça: “Use Playwright CLI para abrir a aplicação local, testar login e gerar screenshots dos erros.”

O CLI funciona fora dos agentes. Verifique onde o instalador colocou a skill; se for exclusiva do Claude, consulte o README para integrá-la ao Codex ou instrua o Codex a usar o CLI diretamente.

ReferênciaPadrão aberto

5. Agent Skills

Não é uma skill específica: é o formato/ecossistema de instruções reutilizáveis (normalmente um arquivo SKILL.md) que diferentes agentes conseguem carregar. O CLI npx skills instala skills de repositórios compatíveis.

Documentação do instalador: vercel-labs/skills • Especificação: agentskills.io

Comandos úteis
npx skills find angular
npx skills list
npx skills update
No Claude Code — como usar
Instale uma skill específica e depois peça a tarefa em linguagem natural. O agente carrega as instruções quando a descrição da skill combina com o trabalho.
No Codex — instalar ou preparar
npx skills find angular
npx skills add anthropics/skills -g -a codex
No Codex — como usar
Peça: “Mostre as skills disponíveis e use a mais adequada para revisar meu componente.”

Agent Skills é um padrão. O comando acima é um exemplo de coleção, não uma instalação de “Agent Skills” como uma única skill.

CLI + SkillEntender codebase

6. Graphify

Analisa código, documentação, esquemas SQL e configurações e constrói um grafo de conhecimento consultável. Ajuda a descobrir relações entre módulos, funções e arquivos sem depender de um índice vetorial.

Repositório oficial: Graphify-Labs/graphify. Requer Python 3.11.5–3.14 e uv (ou pipx).

No Claude Code — Instalar CLI e integração Claude Code
uv tool install graphifyy
graphify install
Como usar dentro do projeto
“/graphify .” para criar/consultar o grafo do projeto. Depois pergunte: “Quais módulos dependem do serviço de autenticação?”

O comando graphify install instala instruções/integração local; não configura por si só um servidor MCP remoto.

No Codex — instalar ou preparar
uv tool install graphifyy
graphify --help
No Codex — como usar
Peça: “Analise as dependências do projeto usando o CLI Graphify, sem presumir que o comando /graphify do Claude exista no Codex.”

Instale o CLI e verifique a ajuda. A integração /graphify e os hooks descritos no repositório podem ser específicos do Claude; não há garantia de slash command equivalente no Codex.

PluginQualidade de código

7. Ponytail

Plugin que orienta o agente a evitar soluções desnecessariamente complexas, excesso de abstrações e código que não agrega valor. Também usa hooks; Node precisa estar disponível no PATH para os hooks funcionarem.

Repositório: DietrichGebert/ponytail

No Claude Code — execute em duas mensagens separadas
/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail
No Claude Code — como usar
“Implemente esta funcionalidade seguindo Ponytail: primeiro procure reutilizar o que já existe e escolha a solução mais simples que atenda aos requisitos.”
No Codex — instalar ou preparar
git clone https://github.com/DietrichGebert/ponytail.git
No Codex — como usar
Peça: “Antes de implementar, procure funcionalidades existentes e prefira a solução mais simples, sem abstrações desnecessárias.”

Ponytail é plugin do Claude; /plugin install não funciona no Codex. Você pode adaptar as instruções públicas do projeto a um AGENTS.md, após revisá-las; hooks não são portados automaticamente.

Skill + hooksDesign quality

9. Impeccable

Kit de vocabulário e revisão visual para agentes de código. Ajuda a criticar, auditar e refinar interfaces, reduzindo problemas comuns de UI genérica. O instalador pode configurar skill e hook de revisão automática.

Repositório: pbakaus/impeccable

No Claude Code — Instalar
npx impeccable install

O instalador pergunta se a instalação será por projeto ou global e oferece o hook quando suportado. Aceite o hook e reinicie/recarregue o Claude Code. Para atualizar: npx impeccable update.

No Claude Code — como usar
/impeccable init
/impeccable critique
/impeccable audit
/impeccable polish
/impeccable animate

Também pode ser instalado como plugin nativo do Claude Code: adicionar o marketplace pbakaus/impeccable e depois instalar Impeccable pela tela /plugin.

No Codex — instalar ou preparar
npx impeccable install
No Codex — como usar
Peça: “Use os princípios do Impeccable para criticar e refinar o dashboard; preserve a arquitetura Angular.”

No instalador, selecione Codex se essa opção estiver disponível. Não presuma que /impeccable init e outros slash commands do Claude estarão presentes no Codex; use instruções em linguagem natural ou as skills que o instalador criar.

SkillGoogle Stitch

10. DESIGN.md — Stitch design-md

Skill do Google Stitch que analisa telas e metadados de um projeto Stitch e gera um DESIGN.md semântico com tokens, cores, tipografia, espaçamentos e padrões de componentes. Exige acesso ao Stitch MCP Server e um projeto Stitch com pelo menos uma tela.

Repositório: google-labs-code/stitch-skills

No Claude Code — Instalar globalmente
npx skills add google-labs-code/stitch-skills --skill design-md -g -a claude-code
No Claude Code — como usar
“Analise as telas do meu projeto no Stitch e gere um DESIGN.md completo documentando o sistema visual.”

Sem o Stitch MCP configurado e acesso ao projeto, essa skill não consegue buscar as telas do Stitch.

No Codex — instalar ou preparar
npx skills add google-labs-code/stitch-skills --skill design-md -g -a codex
No Codex — como usar
Peça: “Com o Stitch MCP configurado, analise as telas do projeto e gere DESIGN.md.”

Sem Stitch MCP e permissão ao projeto, a skill não consegue acessar as telas. A instalação da skill não configura automaticamente o MCP.

ReferênciaDesign system

11. DESIGN.md (arquivo)

É um documento Markdown com a identidade visual do projeto. Não é plugin nem skill por si só. Pode ser criado manualmente ou por uma skill e usado por qualquer agente que leia arquivos do projeto.

Como criar um arquivo inicial
touch DESIGN.md
No Claude Code — como usar
“Leia DESIGN.md antes de alterar qualquer interface. Siga fielmente a paleta, tipografia, escala de espaçamento, componentes, estados e regras responsivas descritas nele.”
No Codex — instalar ou preparar
touch DESIGN.md
No Codex — como usar
Peça: “Leia DESIGN.md e aplique os tokens visuais aos componentes Angular que você modificar.”

Arquivo comum de projeto, não precisa de instalação. Funciona com ambos os agentes quando o arquivo está acessível.

Aguardando identificação do repositório.

Comandos gerais para administrar as skills

Listar skills instaladas

npx skills list

Verificar atualizações

npx skills check

Atualizar skills

npx skills update

Encontrar outras skills

npx skills find
Notas de instalação
  • Skills instaladas com npx skills add ficam no projeto atual por padrão; -g instala no escopo global do usuário.
  • Após instalar, abra uma nova sessão do Claude Code se a skill não aparecer.
  • Plugins do Claude Code são instalados com comandos /plugin dentro do próprio Claude Code; não cole esses comandos diretamente no shell.
  • Confira o README e as permissões de qualquer repositório de terceiros antes de instalar. Skills podem incluir scripts e hooks.
